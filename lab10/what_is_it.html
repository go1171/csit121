What is Accessible Rich Internet Applications (WAI-ARIA)?

WAI-ARIA is a technical specification that provides a framework to improve the accessibility and interoperability of web content and applications. It is primarily for developers to create custom widgets and other web application components with high accessibility. Such as providing full keyboard support that may be implemented in a device-independent way. A few examples are telephones, handheld devices, e-book readers, and televisions.
