Lab 3

In this assignment I learned how to style a HTML document using CSS. CSS makes it easier to manage styles of the HTML document because it keeps the styling outside the HTML to make it less cluttered. Using selectors I can pick and choose which styles I want for specific pieces of text in the HTML document. With CSS I can make my HTML document look more visually appealing and easier to read for any viewer of the page.

Lab 4

Creating this small website was a good exercise in applying beginner web design best practices, particularly regarding CSS and accessibility. Selecting the theme was one of the most enjoyable parts of the project, allowing for a degree of creativity. But translating the theme into an accessible design was challenging. Specifically, determining the appropriate text colors to ensure adequate contrast and readability took careful consideration. Similarly, finding a background image that complemented the theme without overwhelming the content proved to be more difficult than expected. For the visual elements, I used a combination of my own original photos and carefully selected images from Google Images to build the site's aesthetic. Looking back on the process, there are certainly areas where I could expand the project's scope. If I had more time, I would have integrated a wider variety of pictures. Additionally, I would have provided much more detailed, accessible descriptions and alt text for each image to further align with accessibility standards. Ultimately, navigating these design choices helped solidify my understanding of how CSS shapes the user experience.
