Lessons Learned/Reflection

I enjoyed building this website, though it was a bit frustrating at times to get everything to look and function exactly how I wanted. My main personal challenge was getting the site layout to center properly across most screen resolutions. To handle the different screen sizes, I successfully set up two distinct navigation systems tailored for varying resolutions. Ultimately, testing the finished site across multiple devices and browsers went smoothly, and I did not notice any major differences in how it displayed.

Throughout this course, I developed a strong foundational understanding of UI/UX principles while learning how to build solid page layouts using HTML and CSS. I also learned how to embed different types of web media, structure data with tables, and collect user input by building forms. Adding to the site's functionality, I learned how to create an interactive menu and how to write XML. Finally, taking the project from a local build to a live environment taught me the complete process of publishing websites directly to the web.
